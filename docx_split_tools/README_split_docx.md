# Word文檔分割腳本使用說明

## 功能描述

這個腳本可以將BallonTranslator導出的Word文檔按頁面分割成多個獨立的docx文件，每個圖片對應一個docx文件。這對於需要將翻譯工作分配給多個翻譯人員或需要單獨處理每個頁面的情況非常有用。

## 腳本文件

1. **`split_docx_by_pages.py`** - 通用Word文檔分割腳本
2. **`split_ballontranslator_docx.py`** - 專門針對BallonTranslator文檔結構的優化版本

## 安裝依賴

在使用腳本之前，請確保已安裝必要的Python庫：

```bash
pip install python-docx
```

## 使用方法

### 基本語法

```bash
python split_ballontranslator_docx.py <input_docx> [options]
```

### 參數說明

- `input_docx`: 輸入的BallonTranslator Word文檔路徑（必需）
- `-o, --output-dir`: 輸出目錄（可選，默認為原文件同目錄下的 `[文件名]_split` 文件夾）

### 使用示例

#### 1. 基本使用（自動生成輸出目錄）
```bash
python split_ballontranslator_docx.py imgtrans_41.docx
```
這會在 `imgtrans_41_split` 文件夾中生成分割後的文件。

#### 2. 指定輸出目錄
```bash
python split_ballontranslator_docx.py imgtrans_41.docx -o ./split_results
```
這會在 `./split_results` 目錄中生成分割後的文件。

#### 3. 使用完整路徑
```bash
python split_ballontranslator_docx.py /path/to/imgtrans_41.docx -o /path/to/output
```

### 輸出文件格式

分割後的文件會按照以下格式命名：
- `001_頁面名稱.docx`
- `002_頁面名稱.docx`
- `003_頁面名稱.docx`
- ...

每個文件包含：
- 頁面標題（居中，粗體）
- 分隔線
- 原始表格內容（包含氣泡圖片和翻譯文本）

## 輸出文件結構

```
輸出目錄/
├── 001_頁面1名稱.docx
├── 002_頁面2名稱.docx
├── 003_頁面3名稱.docx
├── ...
└── 分割摘要.txt
```

### 分割摘要文件

`分割摘要.txt` 包含以下信息：
- 原始文件名和路徑
- 分割時間
- 總頁面數
- 頁面列表
- 生成的文件列表

## 適用場景

1. **多人協作翻譯**：將不同頁面分配給不同的翻譯人員
2. **分批處理**：需要單獨處理某些頁面
3. **文件管理**：將大型文檔拆分為更小的文件
4. **備份管理**：為每個頁面創建獨立的備份

## 注意事項

1. **文件格式**：此腳本專門針對BallonTranslator導出的Word文檔結構進行優化
2. **文件名限制**：腳本會自動處理文件名中的特殊字符，並限制文件名長度
3. **圖片處理**：腳本會保留原始文檔中的圖片和表格格式
4. **編碼支持**：支持UTF-8編碼，可以正確處理中文、日文等字符

## 錯誤處理

如果遇到錯誤，腳本會：
1. 顯示詳細的錯誤信息
2. 提供錯誤堆疊跟踪
3. 返回非零退出碼

常見錯誤及解決方案：

- **找不到文件**：檢查輸入文件路徑是否正確
- **權限錯誤**：確保有寫入輸出目錄的權限
- **格式錯誤**：確保輸入文件是有效的Word文檔

## 與BallonTranslator的集成

這個腳本與BallonTranslator的工作流程完美配合：

1. 在BallonTranslator中完成翻譯工作
2. 導出為Word文檔（.docx格式）
3. 使用此腳本分割文檔
4. 將分割後的文件分配給翻譯人員進行校對或進一步編輯
5. 完成後可以重新合併或單獨處理

## 技術細節

### 文檔結構解析

腳本會解析Word文檔的XML結構，識別：
- 頁面標題（段落元素）

- 使用3位數字前綴確保排序
- 自動處理特殊字符
- 限制文件名長度避免系統限制

### 格式保持

- 保持原始表格結構
- 保留圖片和格式信息
- 維持文本樣式和對齊方式
