# 分割後 Word 文檔格式指南

## 1. 總體介紹

本文檔詳細說明了由 `split_ballontranslator_docx.py` 腳本生成的單頁 Word 文檔的內部結構和格式標準。每個 `.docx` 文件代表原始漫畫（或文檔）中的一個獨立頁面，其設計目標是為了方便翻譯、校對和後續的自動化處理。

這些文件的格式嚴格遵循 `BallonTranslator` 內部 `dump_doc` 函數生成的原始格式，以確保與主程序的最大兼容性。

## 2. 文件結構

每個分割後的 `.docx` 文件都包含以下兩個核心部分：

1.  **頁面標題 (Page Title)**
2.  **內容表格 (Content Table)**

### 2.1. 頁面標題 (Page Title)

*   **內容**: 通常是該頁面在 `BallonTranslator` 項目中的原始圖片文件名（例如, `page_001.jpg`）。
*   **格式**:
    *   **樣式**: `Normal` (Word 的默認樣式)
    *   **字體**: `Arial`
    *   **對齊**: 左對齊
    *   **修飾**: 無（沒有加粗、斜體或下劃線）
*   **作用**: 作為該文檔所對應頁面的唯一標識符，在後續合併或數據處理中至關重要。

### 2.2. 內容表格 (Content Table)

緊跟在頁面標題之後的是一個兩列的表格，詳細記錄了該頁面上所有文本氣泡（Text Blocks）的內容。

*   **表格樣式**: `Table Grid` (帶有所有內外框線的標準表格)
*   **結構**:
    *   **行數**: 等於該頁面上的文本氣泡數量。
    *   **列數**: 固定為 2 列。

#### 表格列定義

| 列 | 內容                               | 格式                                                                                                       | 說明                                                                                                                       |
| -- | ---------------------------------- | ---------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **第 1 列** | **氣泡截圖 (Bubble Snapshot)** | 包含一張從原始頁面截取下來的圖片，顯示了文本氣泡的具體位置和外觀。 | 這張圖片是該行文本的視覺參照，幫助翻譯人員理解上下文。 |
| **第 2 列** | **翻譯文本 (Translated Text)** | 純文本格式，字體為 `Arial`。                                          | 這是該氣泡對應的翻譯內容。協作者需要編輯或校對此處的文本。 |

#### 表格行定義

表格中的每一行都代表頁面上的一個獨立文本氣泡，並嚴格按照從上到下、從左到右的順序排列。

## 3. 數據與元數據

雖然在 Word 文檔中不明顯可見，但請注意以下幾點：

*   **圖片內嵌元數據**: 每個氣泡截圖的 `.jpg` 文件在導出時，其 EXIF 元數據中包含了該文本氣泡的詳細信息（如坐標、原始文本、字體樣式等）。雖然分割腳本目前不直接處理這些元數據，但在 `BallonTranslator` 的完整工作流中，這些信息是實現數據回導的關鍵。
*   **無額外格式**: 分割後的文檔**不包含**任何多餘的格式元素，如手動換頁符（除了表格後的隱式分頁）、頁眉、頁腳或手動樣式修改。這種簡潔性是為了保證自動化處理的可靠性。

## 4. 協作者須知

如果您是翻譯或校對人員，請遵循以下指南：

1.  **僅修改第二列**: 您的工作範圍是修改內容表格中**第二列**的翻譯文本。
2.  **不要改變結構**: 請不要添加或刪除表格的行或列，也不要修改第一列的圖片。
3.  **保持格式**: 盡量不要對翻譯文本應用複雜的格式（如更改字體、顏色等），除非有特殊要求。
4.  **保存文件**: 完成後，直接保存 `.docx` 文件即可。

遵循以上指南可以確保您修改後的文件能夠被順利地合併回主項目中。
